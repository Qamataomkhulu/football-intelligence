This directory holds the pipeline's JSON output:

- `latest.json` - written by `scripts/run_pipeline.py`, served by the FastAPI backend and read directly by the frontend dashboard.
- `performance.json` - written by `scripts/settle_results.py`, powers the `/performance` page.

Both are generated files, not hand-edited. They're gitignored from automatic
commits except when the GitHub Actions workflows commit fresh runs.
